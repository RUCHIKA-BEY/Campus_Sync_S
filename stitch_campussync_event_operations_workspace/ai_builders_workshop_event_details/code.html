About the Workshop

Autonomous agent architectures are rapidly redefining modern software development. In this intensive two-hour lab, CodeCamp leads will demystify how multi-step reasoning, tool execution, and context persistence operate under the hood in contemporary LLM systems.

Participants will construct a fully functioning autonomous agent capable of scraping campus research directories, executing custom Python sandbox tools, and synthesizing technical briefing memos. You’ll leave with operational code deployable immediately in capstone projects or research workflows.
